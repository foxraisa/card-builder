# Шаг 4. Настройка рабочего окружения

> Дата: 2026-10-11. Описана фактическая конфигурация, на которой выполнялся проект.
> Версии зафиксированы командами `node -v`, `npm -v`, `git --version`, `claude --version`.

| Компонент | Версия | Назначение |
|---|---|---|

| Git | 2.51.2.windows.1 | Контроль версий; Claude Code использует его напрямую |
| **Claude Code (CLI)** | **2.1.296** | Выбранный AI-агент |

## 2. Установка и настройка Claude Code

1. Claude Code устанавливается как CLI-инструмент (npm-пакет), проверка установки:
   `claude --version` → `2.1.296 (Claude Code)`.
2. Авторизация и подключение модели: в соответствии с выбранным решением
   ([03-choice.md](03-choice.md)) агент работает с моделью **GLM от Z.AI**. Claude Code
   допускает сторонние модели через Anthropic-совместимый endpoint: в конфигурации
   окружения задаются адрес endpoint'а Z.AI и ключ доступа (GLM Coding Plan).
   Значения ключей хранятся только в локальной конфигурации пользователя и в репозиторий
   не попадают.
3. Первый запуск: `claude` в корне проекта — агент подхватывает локальную папку как
   рабочую, читает `AGENTS.md` (авто-генерируемый `next dev` файл с предупреждением
   об изменениях в новой версии Next.js) и работает с git.

## 3. MCP (Model Context Protocol)

**Решение: MCP для данной задачи не требуется** — задание предполагает настройку MCP
«если требуется». Обоснование:

- Задача замкнута на локальный проект: агенту нужны только файлы, терминал и git —
  всё это Claude Code делает нативно, без внешних инструментов.
- Секреты (ключ GigaChat) читаются серверным кодом из `.env` в рантайме; давать агенту
  дополнительные каналы доступа к внешним системам смысла нет.
- Минимизация поверхности интеграций соответствует требованию безопасности из
  [01-requirements.md](01-requirements.md).

Если потребуется (например, автоматизация скриншотов через браузер), подключение —
одна команда вида `claude mcp add playwright -- npx @playwright/mcp@latest`;
инструменты появятся у агента в следующих сессиях.

## 4. Настройка тестового проекта

Тестовым проектом для проверки работы агента служит сам **card-builder**.

1. `npm install` — зависимости (Next.js 16.4, React 19, SDK `gigachat`).
2. `.env.local` (в git не попадает, `.gitignore`):

   ```bash
   GIGACHAT_AUTH_KEY=<Authorization Key из кабинета developers.sber.ru>
   GIGACHAT_SCOPE=GIGACHAT_API_PERS
   # Модель: генерация картинок стабильно работает на Pro/Max
   GIGACHAT_MODEL=GigaChat-Pro
   # TLS: у endpoints GigaChat корневой сертификат Минцифры;
   # правильный путь — NODE_EXTRA_CA_CERTS, переменная ниже — только для песочницы
   GIGACHAT_INSECURE_TLS=true
   ```

3. Запуск: `npm run dev` → http://localhost:3000.
